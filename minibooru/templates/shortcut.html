Send to {{ brand.name }} from the iPhone

Set this up once in Apple's Shortcuts app. Then in Photos (or Files) pick pictures or videos, tap the share button and choose Send to {{ brand.name }}. No Safari, no file picker. The phone must be able to reach this server (for example with Tailscale on).

Make the Shortcut

  1. Open Shortcuts, tap ＋, and name it Send to {{ brand.name }}.
  2. Tap the ⓘ (or the arrow next to the name, then Details) and turn on Show in Share Sheet. Under what it accepts, keep Images, Media and Files.
  3. Add the action Repeat with Each and set it to repeat with each item in Shortcut Input.
  4. Inside the repeat, add Get Contents of URL:
    • URL: paste the address above.
    • Tap Show More. Method: POST.
    • Headers: add one. Key X-Upload-Key, value: paste the upload key.
    • Request Body: Form. Add a field of type File. Key files, value Repeat Item.
    • Optional tags: add a Text field, key tags, value like phone (space between tags).
  5. After End Repeat, add Show Notification and put Repeat Results in it. It shows the server's answer for each file, like "1 new" or "1 already in the archive".

iPhone photos (HEIC) are turned into JPEG on arrival, so every browser can show them. Videos are kept as they are. Photos only stored in iCloud must download to the phone first. If one doesn't, the answer says "didn't arrive".

New key

If the key got out, make a new one. The old one stops working right away, so paste the new one into the Shortcut's header.
